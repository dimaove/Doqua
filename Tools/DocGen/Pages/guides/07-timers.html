Timers and windows

Timers

[[Timer]] works like JavaScript timers. Callbacks run on the GUI thread from the event loop, so they can change controls directly. Call the timer methods from the GUI thread too; from another thread, post the call (see Threads).

using Timer = Doqua.GUI.Timer;

var clock = Timer.SetInterval(() => label.Text = DateTime.Now.ToString("HH:mm:ss"), 1000);
Timer.SetTimeout(() => status.Text = "", 2000);   // once, after two seconds
Timer.ClearInterval(clock);                       // stop

Windows

[[Application.Run]] shows the main window and returns when it is closed. Other windows can be created and shown with [[Window.Show]]; closing them does not end the application. A window has a [[Window.Title]], a client size ([[Window.Width]], [[Window.Height]]), a [[Window.Background]] and [[Window.Icons]] (one bitmap per size for the title bar and the task bar).

var window = new Window { Title = "Settings", Width = 400, Height = 300 };
window.Icons = [Bitmap.Load("icon16.png"), Bitmap.Load("icon32.png")];
window.Closed += (sender, e) => SaveSettings();
window.Show();

Dialog windows

[[Window.ShowModal]] shows a window as a modal dialog of another one. It returns at once; until the dialog closes, its [[Window.Owner]] gets no mouse or keyboard input, and a click on the owner brings the dialog to the front. The dialog stays above its owner, has no taskbar entry, opens centred over the owner and closes with it. Set [[Window.Resizable]] to false for a fixed size. The result is whatever the dialog stores before it closes; read it in [[Window.Closed]].

var name = new Input { X = 16, Y = 16, Width = 268 };
var ok = new Button { X = 184, Y = 60, Text = "OK" };
var dialog = new Window { Title = "Rename", Width = 300, Height = 108, Resizable = false, Content = new Panel { Children = { name, ok } } };
var accepted = false;
ok.Click += (sender, e) => { accepted = true; dialog.Close(); };
dialog.Closed += (sender, e) =>
{
    if (accepted)
        Rename(name.Text);
};
dialog.ShowModal(window);

[[MessageBox]] is such a dialog, ready made.
