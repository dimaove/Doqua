Layout

Position and size

A control's [[Control.X]] and [[Control.Y]] are relative to its parent; [[Control.Width]] and [[Control.Height]] are its size (or all four at once: [[Control.Bounds]]). The window's [[Window.Content]] always fills the window.

Anchors

[[Control.Anchor]] keeps a control at fixed distances from its parent's edges when the parent is resized. For each direction:

  • Left and Right: the control stretches (X = Left, Width = parent width − Left − Right).
  • only Left: fixed width at X = Left; only Right: fixed width, stuck to the right edge.
  • neither: the control keeps its X and Width.
// Stretches horizontally, 20 pixels from both sides:
var name = new Input { Anchor = new Anchor(Left: 20, Top: 20, Right: 20) };
// Stays in the bottom-right corner:
var ok = new Button { Anchor = new Anchor(Right: 10, Bottom: 10), Text = "OK" };
// Fills the parent with a 10 pixel margin:
var list = new Table { Anchor = Anchor.Fill(10) };

Anchors are applied again whenever the parent's size changes, when the control is added to a parent and when it resizes itself (an auto-sized [[Label]] anchored to the right keeps its right edge).

Scrolling panels

With [[Panel.ScrollBars]] a panel shows scroll bars when its children extend past its edges; the mouse wheel scrolls (Shift+wheel horizontally) and a child that receives the keyboard focus is scrolled into view. Anchors inside a scrolling panel refer to its visible area, so stretched children never cause scrolling.

var list = new Panel { Anchor = Anchor.Fill(), ScrollBars = ScrollBars.Vertical };
for (var i = 1; i <= 50; i++)
    list.Children.Add(new CheckBox($"Option {i}") { X = 8, Y = 6 + (i - 1) * 24 });

Split panels

[[SplitContainer]] shares its space between [[SplitContainer.Panel1]] and [[SplitContainer.Panel2]]; the user drags the bar between them. Panel1 keeps its size ([[SplitContainer.SplitterDistance]]) when the container is resized.

var split = new SplitContainer { Anchor = Anchor.Fill(8), Panel1MinSize = 120 };
split.Panel1.Children.Add(new TreeView { Anchor = Anchor.Fill() });
split.Panel2.Children.Add(new Table { Anchor = Anchor.Fill() });
split.SplitterDistance = 230;

Tabs

A [[TabControl]] shows one [[TabPage]] at a time in the area below its tabs; each page is a [[Panel]] with a [[TabPage.Title]].
