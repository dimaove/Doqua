Controls

The ready-made controls in Doqua.Controls, in the classic desktop style. All of them derive from [[Control]], so they share its position, size, [[Control.Anchor]], [[Control.Visible]], [[Control.Enabled]], mouse, keyboard and focus events, [[Control.Cursor]] and [[Control.ContextMenu]].

Containers

[[Panel]] holds child controls and can scroll its content ([[Panel.ScrollBars]]). [[TabControl]] shows one [[TabPage]] at a time. [[SplitContainer]] puts two panels side by side with a draggable bar. [[GroupBox]] is a panel with an etched frame and a title, for related controls; disabling it disables its contents.

Text

[[Label]] shows text in any [[Font]] and [[Color]]. [[Input]] is a single-line editor, [[TextArea]] a multi-line one; both support selection, the clipboard and a Cut / Copy / Paste context menu. [[Input.MaxLength]] limits what the user can type or paste.

Buttons and choices

[[Button]] raises [[Button.Click]]. [[CheckBox]] toggles [[CheckBox.Checked]]. [[RadioButton]]s belong to a [[RadioGroup]] that holds the selected value.

Values

[[ComboBox]] picks one item from a drop-down list. [[NumberInput]] edits an integer within a range, with up / down buttons. [[DateInput]] picks a date from a calendar.

Files and folders

[[FileInput]] is a path field with a "..." button that opens a file browser. The path can also be typed; [[FileInput.Error]] says why it is not acceptable (the text is drawn red), or is null when it is. The options: [[FileInput.Mode]] (a file or a folder), [[FileInput.MustExist]], [[FileInput.Required]], [[FileInput.Filters]] with [[FileFilter]] masks and [[FileInput.MatchFilter]], and [[FileInput.BaseDirectory]] with [[FileInput.RelativePaths]] for paths relative to a folder.

var key = new FileInput
{
    Required = true,
    Filters = { new FileFilter("Keys", "*.pem", "*.key"), FileFilter.AllFiles },
};
key.TextChanged += (sender, e) => status.Text = key.Error ?? "";

Data

[[Table]] shows rows of text cells with resizable columns; each cell can have its own font and color. [[TreeView]] shows a hierarchy of [[TreeNode]]s.

With [[Table.RowSelection]], a click or the arrow keys select a row ([[Table.SelectedIndex]], [[Table.SelectionChanged]]), and a double click or Enter raise [[Table.RowActivated]], e.g. to edit the row:

var ports = new Table { RowSelection = true, Columns = { new TableColumn("Port", 80), new TableColumn("Type", 160) } };
ports.SelectionChanged += (sender, e) => remove.Enabled = ports.SelectedIndex >= 0;
ports.RowActivated += (sender, e) => Edit(e.Row);

Messages

[[MessageBox]] shows a message in a small modal dialog window over its owner: an icon, the text and OK, OK / Cancel, Yes / No or Yes / No / Cancel. While it is open, the owner gets no input (see dialog windows). [[MessageBox.Show]] returns at once; the chosen button arrives in a callback, so no async code is needed:

MessageBox.Show(window, $"Remove \"{name}\"?", "Remove", MessageBoxButtons.YesNo, MessageBoxIcon.Question, result =>
{
    if (result == MessageBoxResult.Yes)
        Remove(name);
});

Menus and shapes

[[MainMenu]] is a window's menu bar: [[MainMenuItem]] titles across the top, each opening a list of [[MenuItem]]s. A '&' in a title marks its Alt key ("&File" opens with Alt+F), F10 opens the first menu, and the arrow keys move through the menus. An item's shortcut text ("Ctrl+O", "F5") is also its shortcut in the whole window. The bar anchors itself to the top of its parent; leave [[Control.Height]] pixels free for it there.

var open = new MenuItem("Open...", "Ctrl+O");
open.Click += (sender, e) => OpenFile();
var exit = new MenuItem("Exit", "Ctrl+Q");
exit.Click += (sender, e) => window.Close();
var menu = new MainMenu
{
    Items =
    {
        new MainMenuItem("&File") { Items = { open, MenuItem.Separator(), exit } },
        new MainMenuItem("&Help") { Items = { new MenuItem("About") } },
    },
};
var content = new Panel { Anchor = new Anchor(Left: 0, Top: menu.Height, Right: 0, Bottom: 0) };
window.Content = new Panel { Children = { menu, content } };

[[PopupMenu]] is a context or pop-up menu of [[MenuItem]]s. [[Rectangle]] is a filled rectangle, useful as a starting point for your own controls (see Custom drawing).
