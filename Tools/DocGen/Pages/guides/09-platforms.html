Platform notes

Linux (X11)

  • Needs an X11 display (DISPLAY); on Wayland desktops it runs through XWayland.
  • Text input goes through XIM, so keyboard layouts, dead keys and IBus work; shortcuts use the first keyboard layout, so Ctrl+A works in any layout.
  • Fonts come from fontconfig and are drawn with FreeType. The clipboard is the X11 CLIPBOARD selection: text copied from a Doqua application disappears when it exits unless a clipboard manager keeps it.
  • Cursors come from the desktop's cursor theme; window icons use _NET_WM_ICON.

Windows (Win32)

  • Windows 10 or later. Fonts are drawn with GDI; the clipboard, cursors, icons and timers use the standard Win32 functions.
  • The Windows implementation compiles and follows the same design, but has been tested much less than the Linux one.

Current limitations

  • No high-DPI scaling: one pixel is one device pixel.
  • No font fallback: characters missing from a font (for example CJK in a Latin font) show as boxes.
  • Menus, drop-down lists and calendars are drawn inside their window and cannot extend past its edges.
  • No undo in text editors, no word wrap, no drag and drop between controls.
