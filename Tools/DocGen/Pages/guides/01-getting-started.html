Getting started

Doqua is a .NET 10 class library (doqua.dll, project Sources/Doqua.csproj). An application references it, creates a [[Window]] with some controls and hands it to [[Application.Run]].

Requirements

  • .NET 10 SDK.
  • Linux with an X11 display (also XWayland), and the usual desktop libraries: libX11, fontconfig and FreeType. Or Windows 10/11.

Create a project

dotnet new console -n MyApp
cd MyApp
dotnet add reference ../Doqua/Sources/Doqua.csproj

Then replace Program.cs:

using Doqua.Controls;
using Doqua.GUI;

class MainWindow : Window
{
    public MainWindow()
    {
        Title = "My application";
        Width = 480;
        Height = 300;

        var name = new Input { Anchor = new Anchor(Left: 90, Top: 20, Right: 20) };
        var greeting = new Label { Anchor = new Anchor(Left: 20, Top: 70) };
        var hello = new Button { Anchor = new Anchor(Right: 20, Bottom: 20), Text = "Say hello" };
        hello.Click += (sender, e) => greeting.Text = $"Hello, {name.Text}!";

        Content = new Panel
        {
            Children = { new Label { X = 20, Y = 26, Text = "Name:" }, name, greeting, hello },
        };
        name.Focus();
    }
}

static class Program
{
    [STAThread]
    static int Main() => Application.Run(new MainWindow());
}

dotnet run opens the window. The name field stretches with the window and the button stays in the bottom-right corner, because of their [[Control.Anchor]]s (see Layout).

[STAThread] is harmless on Linux and lets Windows use the clipboard and other COM based features.

The examples

The repository has one example per topic in Examples/. Build them all with dotnet build Examples/examples.sln, run one with dotnet run --project Examples/Tabs, and see the examples gallery for screenshots and sources.

Namespaces

  • Doqua.GUI: [[Window]], [[Application]], [[Control]], drawing ([[DrawingContext]], [[Bitmap]], [[Font]], [[Color]]), input event arguments, [[Clipboard]], [[Timer]], [[Cursor]] and [[Localization]].
  • Doqua.Controls: the ready-made controls, from [[Panel]] and [[Button]] to [[Table]] and [[TreeView]].

With implicit usings, System.Threading.Timer is also in scope; outside Doqua.GUI write using Timer = Doqua.GUI.Timer; to use Doqua's [[Timer]].
