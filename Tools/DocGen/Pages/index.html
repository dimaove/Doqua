Doqua

A small cross-platform GUI library for .NET, in the classic desktop style. One code base runs on Linux (X11) and Windows, with no native dependencies beyond what the system already has.

  • Windows, a control tree and anchored layout
  • Classic 3D look: buttons, tabs, check boxes, scroll bars
  • Text input, multi-line editor, selection, clipboard
  • Combo boxes, number and date inputs with a calendar
  • File and folder inputs with a built-in file browser
  • Tables with row selection and resizable columns, tree views, split panels
  • Modal dialog windows, message boxes, group boxes
  • Context menus, keyboard focus, mouse cursors
  • Native font rendering, PNG images, custom drawing
  • Timers, window icons, localization (English by default)

A first window

using Doqua.Controls;
using Doqua.GUI;

var status = new Label { X = 20, Y = 60, Text = "Not clicked yet" };
var button = new Button { X = 20, Y = 20, Text = "Click me" };
button.Click += (sender, e) => status.Text = "Clicked!";

return Application.Run(new Window
{
    Title = "Hello, Doqua",
    Width = 320,
    Height = 120,
    Content = new Panel { Children = { button, status } },
});

[[Application.Run]] shows the window and runs the event loop until it is closed. Every window has one [[Window.Content]] control, usually a [[Panel]] that holds the other controls. Start with Getting started, or browse the examples:
