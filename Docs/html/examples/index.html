Examples

The Examples folder has one project per example; build them all with dotnet build Examples/examples.sln and run one with dotnet run --project Examples/Simple.

SimpleAnchored panels with clickable rectangles, buttons, an input, a live clock and a status line.TabsA TabControl with pages for text, shapes, check boxes, radio groups in group boxes and scrolling panels, plus context menus.DictionaryA TreeView and a Table in a SplitContainer: each node keeps its own key/value pairs and cell colors; rows can be selected, edited and removed (with a MessageBox asking first).EditorA multi-line TextArea with scroll bars and a caret position status line.DateTimeTwo DateInputs whose ranges limit each other, and a date format selector.FilesFileInputs with different options: required, file masks, new files, folders and relative paths, with their validation messages.FontsAll installed font families in a ComboBox, with size and style controls and a live preview.LocalizationSwitching the whole user interface between English and Russian at run time.ThreadsA background reader posting values to the GUI, an async button that awaits work on the thread pool, Progress<T>, and the error for a control touched from another thread.BitmapLoading, drawing, scaling and saving PNG images, and drawing into a bitmap.ClockA custom control drawing an analog clock with lines and ellipses, redrawn every second.
