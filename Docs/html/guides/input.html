Mouse, keyboard and focus

Mouse

Every control raises Control.MouseDown, Control.MouseUp, Control.MouseClick (press and release on the same control), Control.MouseMove, Control.MouseEnter, Control.MouseLeave and Control.MouseWheel. Coordinates are relative to the control. MouseEventArgs.ClickCount is 2 for a double click, 3 for a triple click.

The control that received a MouseDown also gets the matching MouseUp and all moves while the button is held, even outside it — that is how dragging works. Disabled controls get no mouse events but still cover the controls below them.

rectangle.MouseClick += (sender, e) =>
    status.Text = $"{e.Button} click at ({e.X}, {e.Y})";

Keyboard focus

One control per window has the keyboard focus: Window.FocusedControl, or Control.Focused on the control itself. Controls that can take it have Control.Focusable; a click focuses them, Tab and Shift+Tab move through them in tree order, and Control.Focus moves the focus from code. A radio group is a single Tab stop (Control.IsTabStop).

Keys and text

Control.KeyDown reports keys (Key and KeyModifiers); Control.TextInput reports the typed text, as produced by the keyboard layout and input method. Both start at the focused control and go up through its parents until one sets Handled, then Window.KeyDown gets what is left.

nameInput.KeyDown += (sender, e) =>
{
    if (e.Key == Key.Enter)
    {
        Save();
        e.Handled = true;
    }
};

Context menus

Set Control.ContextMenu to a PopupMenu: it opens on a right click (or Shift+F10). PopupMenu.Closed reports the chosen MenuItem, or null when the menu was dismissed; each item also has a MenuItem.Click event. Input and TextArea add Cut / Copy / Paste to your items; Table lets you build the menu for the clicked cell in Table.ContextMenuOpening.

var menu = new PopupMenu { Items = { new MenuItem("Red"), new MenuItem("Blue"), MenuItem.Separator(), new MenuItem("Reset") } };
menu.Closed += (sender, e) => status.Text = e.SelectedItem?.Text ?? "Closed without a choice";
rectangle.ContextMenu = menu;

Cursor and clipboard

Control.Cursor sets the mouse pointer shape over a control (text inputs use Cursor.IBeam). Clipboard.GetText and Clipboard.SetText read and write the system clipboard.
