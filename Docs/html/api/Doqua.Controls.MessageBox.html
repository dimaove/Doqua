MessageBox static class

public static class MessageBox

Namespace Doqua.Controls · Assembly doqua.dll

A modal message inside a window: a title bar, an icon, the text (wrapped to fit) and buttons. While it is shown the rest of the window gets no input; Show returns at once and the result arrives in its callback.

  • The first button is the default. Left / Right and Tab / Shift+Tab move between the buttons; Enter or Space presses the focused one.
  • Escape answers Cancel (No with MessageBoxButtons.YesNo, OK with MessageBoxButtons.Ok).

MessageBox.Show(window, "Save the changes?", "Settings", MessageBoxButtons.YesNo, MessageBoxIcon.Question,
    result => { if (result == MessageBoxResult.Yes) Save(); });
