Style class

public abstract class Style

Namespace Doqua.Controls · Assembly doqua.dll

Derived: ClassicStyle, FlatStyle

The look of all controls: a palette of colors and a method for every part the controls draw (button, input frame, check box, tab, scroll bar, menu, ...). The controls draw through Style.Current; assigning another style redraws every window at once, so the look can change while the program runs.

Doqua has ClassicStyle (the default: Windows 9x/2000 3D look) and FlatStyle (modern flat design). To make your own, derive from either and override what should look different, or derive from Style and implement every part. The colors are init-only properties, so a style can also be adjusted when it is created: Style.Current = new FlatStyle { Accent = Color.FromRgb(0x2E8B57) };

Sizes are the same in every style (the controls lay out their parts; a style draws inside the rectangles it is given), so changing the style never moves anything. Colors set on a control (button.Color = ...) win over the style's; colors that were not set follow the current style.
