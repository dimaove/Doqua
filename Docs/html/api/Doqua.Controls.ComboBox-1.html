ComboBox<T> class

public class ComboBox<T> : Control

Namespace Doqua.Controls · Assembly doqua.dll

Inheritance: Control → ComboBox<T>

Drop-down list in the classic style: a sunken field showing the selected item and an arrow button; clicking opens the list below (or above) it. Items are values of type T, shown with ComboBox<T>. The text cannot be edited.

  • Closed: Up/Down, PageUp/PageDown, Home/End change the selection; F4 or Alt+Down opens the list; typing a letter selects the next item starting with it.
  • Open: the same keys move the highlight, Enter selects, Escape (or a click outside) cancels; the mouse wheel and the scroll bar scroll the list.
