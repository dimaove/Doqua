Button class

public class Button : Control

Namespace Doqua.Controls · Assembly doqua.dll

Inheritance: Control → Button

Push button with centered text, drawn in the classic 3D style: a raised edge, a sunken frame while pressed (the text moves 1 px down and right), a black frame and dotted rectangle when focused, and embossed grey text when disabled. Raises Button.Click on a left-button click or Enter/Space.
