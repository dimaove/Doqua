RadioGroup class

public abstract class RadioGroup

Namespace Doqua.Controls · Assembly doqua.dll

Derived: RadioGroup<T>

Non-visual owner of a set of RadioButtons: at most one of them is selected, and the group, not the buttons, holds that state. The buttons can be anywhere in the control tree. Use RadioGroup<T> to give each button a value.
