API reference

Doqua.GUI namespace

The foundation: windows and the application loop, the control tree, drawing, fonts, bitmaps, input events, the clipboard, timers, cursors and localization.

Classes

BitmapImage in memory: 32-bit pixels with an alpha channel. Loads PNG files.
ControlBase class of all visual components. Control.X and Control.Y are relative to the parent.
ControlCollectionChildren of a container. Keeps Control.Parent in sync.
DrawingContextDraws into a window's framebuffer (in Control rendering) or into a Bitmap (Bitmap.CreateDrawingContext). While rendering a control, coordinates are local to the control and drawing is clipped to its bounds.
KeyEventArgsA key press: the key, the modifiers held and KeyEventArgs.Handled.
MouseEventArgsA mouse button event: the button, the position, the modifiers and the click count.
MouseMoveEventArgsThe pointer moved.
MouseWheelEventArgsMouse wheel rotation; routed from the control under the pointer up through its parents.
TextInputEventArgsText typed by the user, as produced by the keyboard layout and input method.
WindowTop-level window decorated by the OS window manager. Hosts a single Window.Content control (usually a Panel) that always fills the client area.

Static classes

ApplicationRuns the application: shows the main window and processes events until it is closed.
ClipboardSystem clipboard (text only). Call from the UI thread.
LocalizationTexts shown by Doqua and by the application, in the current Localization.Culture (English by default).
TimerJavaScript-style timers. Callbacks run on the UI thread from the event loop, never while another callback or event handler is running. Call these methods from the UI thread.

Records

FontImmutable font description. Font.Size is the em size in pixels. Use font with { Size = 20 } to derive a changed copy.

Structures

DrawingContext.ClipScopeReturned by DrawingContext.PushClip: disposing it restores the previous clip.

Record structures

AnchorDistances in pixels that a control keeps from its parent's edges when the parent is resized. For each axis:
ColorColor with red, green, blue and alpha (opacity) components, 0 to 255 each.
RectRectangle with integer position and size, e.g. the bounds of a control.
SizeWidth and height in pixels.

Enumerations

CursorMouse pointer shape shown over a control.
FontStyleFont style flags; they can be combined: FontStyle.Bold | FontStyle.Italic.
KeyPhysical key, independent of the keyboard layout (letters are those of the first layout).
KeyModifiersModifier keys held during an event; they can be combined.
MouseButtonMouse buttons.
