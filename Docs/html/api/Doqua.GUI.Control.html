Events

EnabledChangedRaised after Control.Enabled changed (not when only a parent's Enabled changed).
GotFocusRaised when the control receives the keyboard focus.
KeyDownRaised when a key is pressed while this control or one of its children is focused. Goes from the focused control up through its parents until handled.
LostFocusRaised when the control loses the keyboard focus.
MouseClickRaised when a mouse button is pressed and released over this control.
MouseDownRaised when a mouse button is pressed over this control.
MouseEnterRaised when the pointer moves onto this control.
MouseLeaveRaised after Control.MouseEnter when the pointer leaves, even if the control was disabled meanwhile.
MouseMoveRaised when the pointer moves over this control, or anywhere while a mouse button pressed over this control is held (so dragging keeps reporting positions).
MouseUpRaised when a mouse button pressed over this control is released, even if the pointer has moved away or the control was disabled meanwhile: every MouseDown gets its MouseUp.
MouseWheelRaised when the mouse wheel turns over this control or one of its children (until handled).
SizeChangedRaised after Width or Height changed; anchored children have already been rearranged.
TextInputRaised with typed text; routed like Control.KeyDown.
VisibleChangedRaised when a mouse button is pressed over this control.
