Input class

public class Input : Control

Namespace Doqua.Controls · Assembly doqua.dll

Inheritance: Control → Input

Single-line text editor.

  • Left/Right (Ctrl: by word), Home/End move the caret; with Shift they extend the selection.
  • Click places the caret, Shift+click extends the selection, dragging selects.
  • Double click selects a word (dragging then extends by words), triple click selects all.
  • Backspace/Delete (Ctrl: by word) delete the selection or a character.
  • Ctrl+A select all; Ctrl+C / Ctrl+Insert copy; Ctrl+X / Shift+Delete cut; Ctrl+V / Shift+Insert paste.

Text wider than the control scrolls to keep the caret visible.
