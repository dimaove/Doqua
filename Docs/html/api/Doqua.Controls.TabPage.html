TabPage class

public class TabPage : Panel

Namespace Doqua.Controls · Assembly doqua.dll

Inheritance: Control → Panel → TabPage

A page of a TabControl: a Panel whose TabPage.Title is shown on its tab. While it belongs to a TabControl, its Control.Visible and Control.Bounds are managed by the TabControl; set Control.Enabled to false to make it unselectable.
