FlatStyle class

public class FlatStyle : Style

Namespace Doqua.Controls · Assembly doqua.dll

Inheritance: Style → FlatStyle

A modern flat Style: light surfaces, 1-pixel borders with rounded corners, an FlatStyle.Accent color for selections, checked boxes and the keyboard focus, chevron arrows and thin scroll bars, and no 3D edges. 

Style.Current = new FlatStyle();                                       // the standard blue accent
Style.Current = new FlatStyle { Accent = Color.FromRgb(0x2E8B57) };    // a green accent
