DrawingContext class

public sealed class DrawingContext

Namespace Doqua.GUI · Assembly doqua.dll

Draws into a window's framebuffer (in Control rendering) or into a Bitmap (Bitmap.CreateDrawingContext). While rendering a control, coordinates are local to the control and drawing is clipped to its bounds.

Nested types

DrawingContext.ClipScopeReturned by DrawingContext.PushClip: disposing it restores the previous clip.
