RadioButton class

public abstract class RadioButton : ToggleControl

Namespace Doqua.Controls · Assembly doqua.dll

Inheritance: Control → ToggleControl → RadioButton

Derived: RadioButton<T>

Option button of a RadioGroup, drawn in the classic style: a sunken circle with a dot. RadioButton.Checked is read from the group. Clicking or Space selects the button; the arrow keys select the next or previous button of the group; the whole group is a single Tab stop. Create RadioButton<T> instances.
