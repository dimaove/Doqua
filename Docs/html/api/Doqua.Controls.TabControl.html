TabControl class

public class TabControl : Control

Namespace Doqua.Controls · Assembly doqua.dll

Inheritance: Control → TabControl

Pages with a strip of tabs on top, drawn in the classic (Windows 9x/2000) style. The selected page fills the area below the tabs; the others are hidden. Disabled pages cannot be selected and their tabs are grey; if every page is disabled, no page is selected or shown. Keys (while focus is inside): Ctrl+Tab / Ctrl+PageDown next page, Ctrl+Shift+Tab / Ctrl+PageUp previous.
