Anchor record struct

public record struct Anchor(int? Left, int? Top, int? Right, int? Bottom)

Namespace Doqua.GUI · Assembly doqua.dll

Distances in pixels that a control keeps from its parent's edges when the parent is resized. For each axis:

  • Left and Right: X = Left and the width stretches so that X + Width + Right = parent width.
  • only Left: X = Left, the width is unchanged.
  • only Right: the width is unchanged and X moves so that X + Width + Right = parent width.
  • neither: X and Width are left alone.

Top and Bottom work the same way vertically. Example: new Anchor(Right: 10, Bottom: 10) keeps a control in the bottom-right corner.
