Panel class

public class Panel : Control

Namespace Doqua.Controls · Assembly doqua.dll

Inheritance: Control → Panel

Derived: GroupBox, TabPage

Container for other controls, positioned by their own X/Y (or Control.Anchor). With Panel.ScrollBars set, the content (the children's right and bottom edges) can be larger than the panel: classic scroll bars appear when needed, the mouse wheel scrolls (Shift+wheel horizontally), and a child that gets the keyboard focus is scrolled into view. Anchors then refer to the visible area, without the scroll bars, so stretched children never make the panel scroll.
