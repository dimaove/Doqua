ClassicStyle class

public class ClassicStyle : Style

Namespace Doqua.Controls · Assembly doqua.dll

Inheritance: Style → ClassicStyle

The classic (Windows 9x/2000) 3D look, Doqua's default Style: grey faces with raised and sunken 2-pixel edges, dotted focus rectangles, embossed disabled text and navy selections. The edge colors are ClassicStyle.Highlight, ClassicStyle.Shadow and ClassicStyle.DarkShadow.
