DateInput class

public class DateInput : Control

Namespace Doqua.Controls · Assembly doqua.dll

Inheritance: Control → DateInput

Date field in the classic style: a read-only field showing DateInput.Value with DateInput.Format, and a button that opens a calendar. The calendar picks a day; its title switches to month and year grids. Dates outside [DateInput.Min, DateInput.Max] cannot be chosen.

  • Closed: Up / Down change the day, PageUp / PageDown the month, the wheel the day; F4, Alt+Down, Space or Enter open the calendar.
  • Open: arrows move by day / week, PageUp / PageDown by month (with Ctrl by year), Home / End to the first / last day of the month, Enter selects, Escape or a click outside cancels.
