Localization static class

public static class Localization

Namespace Doqua.GUI · Assembly doqua.dll

Texts shown by Doqua and by the application, in the current Localization.Culture (English by default).

  • Localization.Get returns a text for a key: the translation for the culture ("ru-RU"), else for its language ("ru"), else Doqua's English default (Localization.DefaultTexts), else the key itself. So an application may use the English text itself as the key: Localization.Get("Hello").
  • Translations come from code (Localization.Add) or from JSON files with one flat object of key / text pairs (Localization.LoadJson).
  • Localization.Culture also gives month and weekday names and date formats (e.g. in DateInput). Changing it redraws all windows and raises Localization.CultureChanged, where the application updates the texts it has set on its controls.

Doqua's own keys start with "Doqua."; exception messages are translated too. Use it from the UI thread.
