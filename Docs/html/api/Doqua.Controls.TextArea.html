TextArea class

public class TextArea : Control

Namespace Doqua.Controls · Assembly doqua.dll

Inheritance: Control → TextArea

Multi-line text editor in the classic style (sunken edge, vertical scroll bar when needed).

  • Enter starts a new line; Tab still moves the focus to the next control.
  • Left/Right (Ctrl: by word), Up/Down, Home/End (Ctrl: whole text), PageUp/PageDown; with Shift they select.
  • Click places the caret, Shift+click and dragging select, double click selects a word, triple click a line.
  • Backspace/Delete (Ctrl: by word); Ctrl+A/C/X/V, Ctrl+Insert, Shift+Insert, Shift+Delete; context menu.
  • Mouse wheel and the scroll bar scroll; the view follows the caret (also horizontally).

Lines are separated by '\n'; "\r\n" and "\r" in assigned or pasted text become '\n'. No word wrap.
