Window class

public class Window

Namespace Doqua.GUI · Assembly doqua.dll

Top-level window decorated by the OS window manager. Hosts a single Window.Content control (usually a Panel) that always fills the client area.

Constructors

Window()Creates an 800 x 600 window; it appears with Window.Show or Application.Run.
