ToggleControl class

public abstract class ToggleControl : Control

Namespace Doqua.Controls · Assembly doqua.dll

Inheritance: Control → ToggleControl

Derived: CheckBox, RadioButton

Base of CheckBox and RadioButton: a small classic box followed by text. A left click (on the box or the text) or Space while focused calls ToggleControl.OnActivated.
