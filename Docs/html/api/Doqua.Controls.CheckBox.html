CheckBox class

public class CheckBox : ToggleControl

Namespace Doqua.Controls · Assembly doqua.dll

Inheritance: Control → ToggleControl → CheckBox

Check box with a title, drawn in the classic style: a sunken 13 x 13 box with a check mark. A left click (on the box or the text) or Space while focused toggles CheckBox.Checked.
