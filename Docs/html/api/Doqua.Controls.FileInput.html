FileInput class

public class FileInput : Control

Namespace Doqua.Controls · Assembly doqua.dll

Inheritance: Control → FileInput

A path field with a "..." button that opens a file browser below the field (above it if there is no room). The path can also be typed. FileInput.Error tells whether it satisfies the options (FileInput.MustExist, FileInput.Required, FileInput.MatchFilter); invalid text is drawn in FileInput.InvalidColor.

  • Field: F4 or Alt+Down open the browser.
  • Browser: click selects, double click (or Enter) opens a folder or chooses a file; Backspace or Alt+Up go to the parent folder; arrows, PageUp / PageDown, Home / End move; a letter jumps to the next name starting with it; Escape or a click outside closes it.

Relative paths are resolved against FileInput.BaseDirectory (the current directory if it is null).
