FileFilter class

public sealed class FileFilter

Namespace Doqua.Controls · Assembly doqua.dll

A named set of file name patterns for FileInput, e.g. new FileFilter("Certificates", "*.pem", "*.crt"). Patterns use * (any characters) and ? (one character) and are matched against the file name only, ignoring case on every platform.
